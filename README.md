# Accoria, site de prezentare (preview)

Site static pentru Accoria (SMART TEAM CONT S.R.L.), construit de AMPLIO. Aceasta este versiunea de previzualizare; adresa finală va fi accoria.ro.

- Textele: `src/content.js`
- Generatorul: `src/build.js` (`node src/build.js` pentru preview, `node src/build.js --prod` pentru accoria.ro)
- Stil și script: `assets/style.css`, `assets/app.js`
- Fonturi: Geologica (SIL Open Font License), găzduită local în `assets/fonts`
